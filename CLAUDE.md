# baukasten-aufgaben

Published digital assignments of the Arbeitsblatt-Baukasten (`noledge5/edutoolboxbuilder`). The app writes the files in `a/` through the GitHub Git Data API; they are data, not code.

- Do not edit, rename or delete files in `a/` by hand: students open them by id and the teacher's app holds the matching keys.
- Changes to the format or the student view belong in `edutoolboxbuilder` (`src/share/`, `src/student/`). Work there following its `CLAUDE.md` („How we work“).
